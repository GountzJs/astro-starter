# Astro Starter Kit

A Yeoman generator for quickly scaffolding Astro projects with a base configuration ready to go.

## Prerequisites

- Node.js (>=23.6.1)
- pnpm (>=10.0.0)

## Installation

Install Yeoman globally:

```bash
pnpm i -g yo
```

Install the generator:

```bash
pnpm i -g generator-astro-starter
```

## Usage

Create a new Astro project:

```bash
yo astro-starter
```

Then navigate to your project and start developing:

```bash
cd your-project-name
pnpm install
pnpm dev
```

## What's Included

- ⚡ Astro base configuration
- 🎨 Tailwind CSS setup
- 📦 Pre-configured project structure
- 🚀 Ready to start coding

## Features

- Zero configuration needed
- Modern tooling setup
- Best practices out of the box
